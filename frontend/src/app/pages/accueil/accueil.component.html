Bienvenue sur le lab

Le lab est un serveur où vous créez vos applications web et les mettez en ligne, sans rien installer chez vous. Chaque application a son adresse, sa base de données et son dépôt GitHub.

Créer

Vous donnez un nom : le lab prépare le dépôt GitHub, la base de données et l'adresse de l'application.

Coder

Un VS Code s'ouvre dans votre navigateur, sur votre projet seulement, avec un terminal et vos assistants.

Mettre en ligne

Vous poussez votre code sur GitHub, puis un bouton le met en service. Vos applications ne voient que vos données.

Trois règles, pour vous comme pour vos assistants

  • Une feuille de route. Chaque projet a un fichier FEUILLE_DE_ROUTE.md : le travail y est découpé en lots, avec les tests à réussir pour chacun.
  • Des tests avant la mise en ligne. Si les tests échouent, rien n'est mis en service : la version précédente continue de tourner.
  • La mise en ligne passe par le lab. Depuis la page du projet ou depuis votre assistant — jamais à la main sur le serveur.
